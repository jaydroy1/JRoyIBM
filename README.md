# JRoyIBM

JRoyIBM is a common platform for Power BI, PowerShell, Claude, MCP, and related automation and integration workflows.

## Purpose

This repository is intended to provide a shared foundation for:

- Power BI reporting and analytics workflows
- PowerShell automation and scripting
- Claude-powered assistant and AI use cases
- MCP-based integrations and tooling
- Other cross-platform extensions built on the same common platform
